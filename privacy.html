GX10 REPORT DELIVERY / 隱私權政策

清楚說明資料與授權的用途。

本政策說明大衛王數位廣告有限公司營運的 GX10 自動報告之 Google Drive 報告交付功能，涵蓋其存取、使用、保存與分享的資料。

存取哪些資料

本功能讀取指定父資料夾的中繼資料與權限，建立期間子資料夾，上傳本機報告，並核對檔案大小、校驗資訊及分享權限。報告可能包含廣告成效及公司營運彙總資訊。

目前實作請求 https://www.googleapis.com/auth/drive。這項權限可管理授權帳號可存取的所有 Drive 檔案，並非 Google 層級只限於指定資料夾。

用途與保存

Google OAuth access token 與 refresh token 用於背景排程授權；由管理員配置於受限的服務憑證位置。工作狀態、檔案識別碼、校驗資訊及寄送結果用於失敗重試與避免重複交付。

歷史報告不自動刪除，新增的交付紀錄也未設定自動清除期限。服務端授權檔及紀錄由管理員管理；刪除、清除授權檔或停止排程的需求，可透過下列聯絡方式提出，由管理員核對權限及保存需求後處理。

Google Drive 與 LINE

Google Drive 保存報告；LINE 接收設定的建案名稱、報告期間及本期資料夾連結。若採免登入連結分享，取得連結的人可閱讀及轉傳；分享前應核對資料擁有者及公司政策。

撤銷授權與刪除

授權人可從 Google 帳戶第三方連線設定撤銷本應用程式的授權，後續 Drive 操作將受影響。撤銷不會自動刪除既有報告、撤回 LINE 訊息或關閉已建立的分享連結。

如需刪除資料、停止排程、撤銷分享或清除服務端授權檔，請寄信至 lukemedia.taipei@gmail.com，說明涉及的建案、期間及申請事項。管理員將核對申請人權限後處理；請勿在申請信中附上密碼、憑證或 token。

資料用途限制

本功能透過 Google Drive API 取得的資料僅用於報告交付、權限核對、失敗重試與避免重複交付，不轉售、不用於廣告，亦不用於訓練一般 AI 模型。既有報告系統的其他資料來源及分析功能不在本頁範圍內。

本功能對從 Google API 接收資訊的使用及轉移，須遵守 Google API Services User Data Policy，包括其 Limited Use 要求。
